# SpotHub API

Адрес: `http://localhost:8080`. Формат: JSON. Ошибки всегда приходят как `{"error":"текст"}`.

Токен (JWT) выдаётся при регистрации и логине и живёт 24 часа. Для защищённых запросов:
`Authorization: Bearer <token>`.

## Авторизация

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| POST | `/api/auth/register` | `{"nickname","email","password"}` | 201 `{"token","id","nickname"}` |
| POST | `/api/auth/login` | `{"email","password"}` | 200 `{"token","id","nickname"}` |

Ник: 3-30 символов. Пароль: 8-72 символа. Занятый ник или email: 409.

## Споты

| Метод | Путь | Токен | Описание |
|---|---|---|---|
| GET | `/api/spots?bbox=lon1,lat1,lon2,lat2&sport=skate` | нет | Споты в видимой области карты (до 500). `sport` необязателен |
| GET | `/api/spots/{id}` | нет | Карточка спота со средними оценками |
| POST | `/api/spots` | да | Создать спот |
| PUT | `/api/spots/{id}/rating` | да | Поставить или обновить свою оценку |

Виды спорта: `skate`, `scooter`, `roller`, `bmx`.

**Элемент списка:** `{"id","title","description","lat","lon","sports":[...]}`

**Карточка:** то же и ещё `author`, `surface` (покрытие), `lighting` (освещение), `security` (охрана) как средние числа, `rating_count`. Если оценок нет, средние равны `null`.

**Создание:** `{"title","description","lat","lon","sports":["skate"]}` возвращает 201 `{"id"}`. Спот получает статус «на проверке» и появится на карте после одобрения модератором. Нужно показать пользователю «Спот отправлен на проверку». Лимит: 10 новых спотов в сутки.

**Оценка:** `{"surface":1-5,"lighting":1-5,"security":1-5}`. Один пользователь = одна оценка на спот, повторный запрос обновляет её.

### Важно про bbox

Порядок: долгота, широта (юго-запад), долгота, широта (северо-восток). `map.getBounds()` в Яндекс.Картах возвращает `[[lat1, lon1], [lat2, lon2]]`, то есть широта идёт первой. Нужно переставить:

    const b = map.getBounds();
    const bbox = `${b[0][1]},${b[0][0]},${b[1][1]},${b[1][0]}`;

А для `ymaps.Placemark` координаты передаются как `[lat, lon]`.

## Кто сейчас на споте

| Метод | Путь | Токен | Описание |
|---|---|---|---|
| GET | `/api/spots/{id}/here` | нет | Список `[{"user_id","user","expires_at"}]` |
| POST | `/api/spots/{id}/checkin` | да | «Я здесь» на 2 часа (повтор продлевает) |
| DELETE | `/api/spots/{id}/checkin` | да | «Ушёл» |

Человек может быть отмечен только на одном споте: новая отметка снимает старую.

## Чат

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/spots/{id}/messages?before=ID&limit=50` | История, новые первыми. Для подгрузки старых передайте `before` = id самого старого полученного сообщения |

Живой чат работает через WebSocket, см. `websocket.md`.

## Жалобы

POST `/api/reports` (нужен токен): `{"target_type":"spot"|"message","target_id":123,"reason":"текст"}`. Одна жалоба от человека на объект. Сообщение, на которое пожаловались трое, скрывается автоматически.

## Коды ошибок

| Код | Значение |
|---|---|
| 400 | Неверные данные (текст ошибки в `error`) |
| 401 | Нет токена, токен неверный или истёк: отправить на логин |
| 403 | Аккаунт заблокирован или нет прав модератора |
| 404 | Не найдено |
| 409 | Ник или email заняты |
| 429 | Слишком много запросов: показать «Подождите немного» |
